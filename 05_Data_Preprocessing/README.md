# ⚙️ 05. Data Preprocessing

This directory focuses on cleaning, transforming, and preparing raw data for machine learning models.

## 🎯 Learning Objectives
- Handling Missing Values (Imputation, Deletion)
- Encoding Categorical Data (One-Hot Encoding, Label Encoding)
- Feature Scaling (Standardization, Normalization)
- Outlier Detection and Handling
- Data Splitting (Train and Test sets)

## 🛠️ Tools
- Python (Pandas, NumPy, Scikit-Learn)
