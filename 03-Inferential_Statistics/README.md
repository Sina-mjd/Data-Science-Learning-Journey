# 🧪 04. Inferential Statistics and Statistical Tests

This directory focuses on drawing conclusions about populations based on sample data and applying statistical tests.

## 🎯 Learning Objectives
- Hypothesis Testing (Null and Alternative)
- P-value and Statistical Significance
- T-tests, ANOVA, and Chi-Square Tests
- Confidence Intervals

## 🛠️ Tools
- Python (Pandas, NumPy, SciPy, Statsmodels)
