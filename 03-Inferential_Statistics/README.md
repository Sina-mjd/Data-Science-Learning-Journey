# 🧪 03git add README.md. Inferential Statistics and Statistical Tests

This directory focuses on drawing conclusions about populations based on sample data and applying statistical tests.

## 🎯 Learning Objectives
- **Normality Checks:** Shapiro-Wilk test, Probability Plot (probplot), and Histograms
- **Parametric Tests (T-Tests):** 1-Sample T-Test, Independent T-Test, and Relative T-Test
- **Non-Parametric Tests:** Mann-Whitney U Test (for non-normal distributions)
- **Categorical Tests:** Chi-Square (Chi2) Test for categorical correlations
- **Simulation:** Statistical simulation methods

## 🛠️ Tools
- Python (Pandas, NumPy, SciPy, Statsmodels, Matplotlib)
