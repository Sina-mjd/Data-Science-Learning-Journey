# 📈 02. Descriptive Statistics

This directory focuses on applying descriptive statistics to understand, summarize, and describe the features of datasets using Python.

## 🎯 Learning Objectives
In this module, I will cover:
- **Measures of Central Tendency:** Mean, Median, and Mode.
- **Measures of Dispersion:** Variance, Standard Deviation, Range, and IQR.
- **Data Distribution:** Skewness, Kurtosis, and Percentiles.
- **Practical Application:** Using Pandas and SciPy for statistical summaries.

## 🛠️ Tools
- Python (Pandas, NumPy)
