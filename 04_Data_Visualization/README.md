# 📊 04. Data Visualization

This directory focuses on the graphical representation of information and data to identify patterns, trends, and outliers.

## 🎯 Learning Objectives
- Core Plot Types (Line, Scatter, Bar, Histogram, Boxplot)
- Advanced Visualizations (Heatmaps, Violin plots, Pairplots)
- Customizing Figures (Axes, Labels, Legends, Colors, Themes)
- Subplots and Grid Layouts
- Visual Exploratory Data Analysis (EDA)
